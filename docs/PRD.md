# PRD: 레퍼런스 아카이브

> 이 문서가 기준이다. AI(Claude Code / Codex)는 이 문서에 적힌 것만 만든다.
> 원래 세션 팩의 "PRD 메이커"를 시각 전공생용 레퍼런스 아카이브로 바꾼 버전이다. 8번 "내 버전"은 Step 4에서 구현한다.

## 1. 한 줄 요약

마음에 드는 이미지를 바로 가져와 짧은 메모를 붙여 두면, AI가 제목과 태그로 조용히 정리해 주고, 그렇게 쌓인 레퍼런스를 보드처럼 다시 훑어보는 시각 전공생용 웹 서비스.

## 2. 문제

- 핀터레스트나 인스타그램에 저장만 해 두고 다시 안 본다. 왜 좋았는지 기억이 안 나서, 크리틱이나 포트폴리오에서 "내 취향과 그 이유"를 말하지 못한다.
- 이미지를 모으는 곳과 메모하는 곳이 따로 놀아서 둘 다 귀찮아진다.
- 이미지를 모을 때 정리(제목 짓기, 분류)까지 하려니 손이 무거워져 결국 안 모은다.

## 3. 타깃 유저

- 1차: 크리틱이나 포트폴리오를 앞두고, 레퍼런스를 모으면서 왜 좋은지 한두 줄씩 남기고 싶은 시각디자인 전공생.
- 2차: 평소 핀터레스트로 레퍼런스를 모으는 다른 시각 전공생(일러스트, 사진, 영상).

## 4. 핵심 기능

| 우선순위 | 기능 | 설명 | 완료 기준 |
|---|---|---|---|
| P0 | 레퍼런스 추가 | 이미지 주소(URL), 출처(선택), 메모를 넣고 저장하면 AI가 메모를 읽고 짧은 제목과 한 줄 요약을 붙인다 | 버튼을 누르고 10초 안에 이미지 + 제목이 붙은 카드가 뜬다 |
| P0 | 자동 저장 | 추가한 레퍼런스가 Supabase `refs` 테이블에 저장된다 | Supabase Table Editor에서 새 row가 보인다 |
| P0 | 보드 | `/refs`에서 모은 레퍼런스를 최신순 이미지 격자로 본다 | 새로고침해도 보드가 그대로 있다 |
| P1 | 상세 / 삭제 | `/refs/[id]`에서 이미지를 크게 보고, 메모·제목·출처를 확인하고 지울 수 있다 | 삭제 후 보드에서 사라진다 |
| P1 | 내 버전 기능 | 8번에서 고른 기능 (태그, 붙여넣기·드래그 추가) | 8번에 적은 완료 기준 |

AI는 조연이다. 이미지를 보고 평가하지 않고, 내가 쓴 메모만 읽고 정리한다.

## 5. 유저 플로우

1. `/`에 들어온다.
2. 이미지 주소를 붙여넣는다 (브라우저에서 이미지 우클릭 > "이미지 주소 복사"). 붙여넣으면 바로 미리보기가 뜬다.
3. 출처(선택)와 메모 한두 줄을 적는다. (예: "여백이 넓어서 제목 하나만 보이는 게 좋다")
4. "저장"을 누르면 로딩 표시가 뜬다 (3~10초).
5. AI가 붙인 제목과 한 줄 요약이 달린 카드가 뜬다.
6. "보드 보기"로 `/refs`에 가서 쌓인 레퍼런스를 훑어본다. 하나를 누르면 상세가 열린다.

## 6. 화면

| 경로 | 이름 | 역할 |
|---|---|---|
| `/` | 추가 | 이미지 주소 + 출처 + 메모 입력, 미리보기, 저장 결과 카드 |
| `/refs` | 보드 | 저장된 레퍼런스 이미지 격자 |
| `/refs/[id]` | 상세 (P1) | 이미지 크게 + 메모·제목·출처 + 삭제 |

## 7. 이번에 안 만드는 것

- 로그인 / 회원가입: 각자 자기 Supabase를 쓰니까 필요 없다.
- AI가 이미지를 직접 보고 분석하는 것. AI는 메모만 읽는다.
- 퓨어레프 같은 자유 배치 캔버스 (이미지 끌어서 옮기기, 확대/축소). 보드는 자동 격자로 충분하다.
- 보드 여러 개 / 폴더 / 컬렉션 나누기
- 공유 링크, 실시간 협업, 결제
- 스트리밍 출력. 로딩 표시로 충분하다.
- 배포: 세션 이후 과제 (Vercel)

## 8. 내 버전 (Step 4에서 구현)

### 8-1. 누구를 위한 서비스인가

- 내 선택: 크리틱이나 포트폴리오에서 "내 취향과 그 이유"를 말할 수 있도록, 레퍼런스 이미지를 바로 모으고 메모를 붙여 자기만의 아카이브를 쌓고 싶은 시각 전공생. AI 분석이 주인공이 아니라, 퓨어레프처럼 이미지를 빠르게 가져와 편하게 메모하고 쌓는 것이 주인공이다.

### 8-2. AI 성격 (프롬프트 톤)

- 내 선택: 말수 적은 아카이브 정리 조수. 내가 쓴 메모를 읽고 짧은 제목과 태그만 붙여 준다. 이미지를 평가하거나 의견을 덧붙이지 않고, 내 메모에 없는 내용을 지어내지 않는다.
- Step 2부터 이 톤으로 `instructions`를 쓴다.

### 8-3. 출력에 추가할 섹션 1개

- 내 선택: 태그 3개 (`tags: string[]`). 형태·색·타이포·구도 같은 시각 요소를 2~6자 명사구로 (예: `비대칭 그리드`, `보색 대비`, `세리프 헤드라인`). 보드 카드 이미지 위에 작은 칩으로 보인다.
- 이 칸은 `docs/API.md`의 "내 버전 필드 추가하는 법" 순서대로 필드를 하나 추가한다.
- 완료 기준 (한 줄): 새로 저장한 레퍼런스의 보드 카드에 태그 칩 3개가 보인다.

### 8-4. 추가 기능 1개

- 내 선택: 이미지 붙여넣기 / 드래그로 바로 추가. `/` 화면 어디서든 `Ctrl+V`(Mac은 `Cmd+V`)로 캡처한 이미지를 붙여넣거나 이미지 파일을 끌어다 놓으면 미리보기가 뜨고, 메모를 적어 저장한다. 이미지 파일은 Supabase Storage `refs` 버킷에 올리고 테이블에는 그 공개 URL만 저장한다. 이미지 주소 붙여넣기도 그대로 쓸 수 있다.
- 완료 기준 (한 줄): 캡처 이미지를 붙여넣고 메모를 적어 저장하면, 새로고침해도 보드에 그 이미지가 보인다.

- [ ] 이미지 주소와 메모를 넣으면 제목이 붙은 카드가 뜬다
