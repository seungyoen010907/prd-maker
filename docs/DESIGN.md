# DESIGN

> 화면을 만들 때 AI가 따르는 규칙. 프리셋 하나를 골라 맨 아래 "내 선택"에 적는다.

## 1. 원칙

- 랜딩페이지가 아니라 도구다. 이미지 넣고 메모하고 저장하는 게 한 화면에서 끝난다.
- 주인공은 레퍼런스 이미지다. 화면 장식은 이미지 뒤로 물러나고, 폼은 조용하게.
- 장식 대신 여백과 위계로 정리한다: 제품명 > 섹션 라벨 > 본문.

## 2. 기술 규칙

- 스타일은 Tailwind만 쓴다 (create-next-app에 이미 들어 있음). shadcn, MUI 같은 UI 라이브러리는 오늘 추가하지 않는다.
- 색은 `app/globals.css`의 CSS 변수로만 정의하고, 컴포넌트에는 hex 값을 직접 쓰지 않는다.
- 변수 이름: `--bg`, `--card`, `--text`, `--muted`, `--border`, `--accent`
- 폰트는 create-next-app 기본값(Geist)을 유지한다. 한글이 어색하면 `next/font/google`의 `Noto_Sans_KR`로 바꿔도 된다.

## 4. 레이아웃

- `/`와 `/refs/[id]`: 본문 최대 너비 672px (`max-w-2xl`), 가운데 정렬, 좌우 패딩 16px.
- `/refs` 보드: 최대 너비 1280px, 좌우 패딩 16px (8번 "바꾸고 싶은 것" 참고).
- 모바일 폭(375px)에서도 가로 스크롤이 생기면 안 된다.
- 헤더: 왼쪽에 서비스 이름 + 한 줄 설명, 오른쪽에 "보드" 링크 (`/refs`에서는 "추가" 링크).

## 5. 컴포넌트

### 입력 폼 (`/`)
- 입력칸은 전체 너비, placeholder에 예시를 넣는다.
  - 이미지 주소: "https://... (이미지 우클릭 > 이미지 주소 복사)"
  - 출처 (선택): "https://www.pinterest.com/pin/..."
  - 메모 (textarea, 3줄): "왜 저장했는지 한두 줄. 예: 여백이 넓어서 제목 하나만 보이는 게 좋다"
- 이미지 주소가 들어오면 입력칸 위에 미리보기를 바로 띄운다 (원래 비율, 모서리 16px, 최대 높이 400px). 이미지를 못 불러오면 "이미지를 불러올 수 없다"를 `--muted`로.
- Step 4(8-4): 미리보기 자리가 비어 있을 때 점선 테두리 박스에 "이미지를 붙여넣거나(Cmd+V) 끌어다 놓기"를 보여준다. 끌어다 놓는 중에는 테두리를 `--text` 색으로.

### 주 버튼
- 전체 너비, `--accent` 배경, 흰 글자.
- 로딩 중에는 비활성화하고 문구를 "정리하는 중... (3~10초)"로 바꾼다.

### 레퍼런스 카드 (`components/RefCard.tsx`)
- 결과 카드와 보드 칸에 같이 쓴다.
- 이미지가 주인공: 카드 너비를 꽉 채우고 원래 비율 유지, 안쪽 여백 없음, 모서리 16px, 그림자 없음.
- 이미지 아래: 제목 (굵게, 16px), 한 줄 요약 (`--muted`, 14px). 보드에서는 제목만.
- Step 4(8-3): 태그는 흰 배경 + 검정 글자의 완전히 둥근 작은 칩(12px)으로 이미지 왼쪽 아래에 얹는다.
- 결과 카드에서는 아래에 내 메모 원문을 `--card` 배경 박스에 그대로 보여준다. AI 제목보다 내 메모가 더 중요하다.

### 보드 (`/refs`)
- CSS `columns`로 메이슨리 격자: 모바일 2열, 태블릿(`md`) 3열, 데스크톱(`lg`) 4열, 간격 8px. 칸마다 `break-inside: avoid`.
- 카드 전체가 `/refs/[id]` 링크다.

### 상세 (`/refs/[id]`, P1)
- 이미지 크게 → 제목 → 한 줄 요약 → 내 메모 → 출처 링크 (있으면) → 저장 날짜 (`--muted`) → 삭제 버튼 (회색, 누르면 `confirm`으로 한 번 묻기).

## 6. 상태 (4개 다 처리)

| 상태 | 표시 |
|---|---|
| 로딩 | 버튼 비활성 + 문구 변경, 보드는 "불러오는 중..." |
| 빈 상태 | "아직 모은 레퍼런스가 없다" + 추가 화면으로 가는 링크 |
| 에러 | 빨간 박스에 서버가 준 `error` 메시지를 그대로 |
| 성공 | 레퍼런스 카드 |

## 7. 하지 말 것 (AI가 만든 티가 제일 많이 나는 것들)

- 이모지를 아이콘 대신 쓰기
- 보라-파랑 그라데이션 배경, 글래스모피즘
- 히어로 섹션, "Get Started" 같은 랜딩 문구
- 카드마다 그림자 진하게
